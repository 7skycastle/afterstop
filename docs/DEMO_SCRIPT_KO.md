# 1분 제품 시연 순서

준비: 태블릿 또는 휴대폰을 가로로 두고 소리를 켭니다. 서버·네트워크는 필요 없습니다.

| 시간 | 화면·동작 | 말할 내용 |
|---|---|---|
| 0:00 | 첫 화면 | "사고 직후 운전자가 메뉴를 찾지 않아도 영상 확보, 장면 분석, 음성 안내가 이어지는 앱입니다." |
| 0:05 | **전체 흐름 시연** (고속도로) | "위쪽 주황색 줄처럼, 지금은 연결을 가정한 시연이라 영상·차량 신호·분석 응답이 모두 예시입니다." |
| 0:10 | 속도·충격 값이 흐르다 '사고 후보 감지' | "충격, 급격한 감속, 정차가 함께 맞으면 사고 후보로 봅니다. 확정 판정이 아니고, 분석을 기다리지 않고 공통 안내부터 시작합니다." |
| 0:18 | 전후 프레임 6장 → 분석 → 하윤 음성 | "사고 전후 장면을 확보해 분석 서버에 보내고, 응답은 실제 모델 응답과 같은 검사를 거친 뒤 안내 문장을 고릅니다." |
| 0:28 | **이동이 어려워요** 누르기 | "이동이 어렵다고 알리면 하차·대피 안내보다 구조 요청 안내가 우선합니다." |
| 0:34 | 시연 상황 **터널 · 연기 의심** → 시연 | "영상에서 연기 의심 단서가 근거 프레임과 함께 나오면 안내가 바뀝니다. 대피 방향은 앱이 정하지 않고 현장 표지로 확인하게 합니다." |
| 0:44 | **야간 · 시야 제한** 결과만 보여주기 | "어두워 판단할 수 없으면 위험이 없다고 하지 않고, 공통 안내를 유지합니다." |
| 0:50 | **과속방지턱** | "충격만 있고 감속·정차 조건이 없으면 사고 안내로 바뀌지 않습니다." |
| 0:55 | **제품 구성** 탭 | "카메라·영상 파일·분석 서버는 실제로 연결되는 구조이고, 현대차 빌트인 캠·충돌 신호·SOS 는 권한이 생기면 바꿔 끼울 어댑터로 비워 두었습니다. 실제 신고는 하지 않습니다." |

시연 후 **기록 저장** → **사건 기록** 탭에서 출처와 미확인 항목이 남은 것을 보여줄 수 있습니다(영상 원본은 저장하지 않음).
