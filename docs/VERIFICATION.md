### 한글 경로 문제 (중요)

작업 폴더 경로에 한글이 있으면 다음 두 가지가 실패했습니다.
1. AGP 경로 검사: `Your project path contains non-ASCII characters` → `gradle.properties`에 `android.overridePathCheck=true`로 해결.
2. 단위 테스트 실행 JVM이 한글이 든 클래스 경로를 읽지 못해 `ClassNotFoundException: com.afterstop.app.CoreTest` 발생. 디렉터리 정션은 Gradle이 실제 경로로 되돌려 효과가 없었습니다.

해결: ASCII 경로의 가상 드라이브에서 빌드합니다(재부팅 또는 `subst Q: /d`로 해제).

```bat
subst Q: "E:\Claude\HD-APP\멈춘다음_Claude_개발인계패키지\afterstop-claude"
cd /d Q:\android
set JAVA_HOME=C:\dev\jdk17
gradlew.bat clean testDebugUnitTest assembleDebug
```
